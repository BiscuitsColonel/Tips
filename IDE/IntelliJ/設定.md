# IntelliJ IDEA で XML を整形すると SQL に差分が出るのを防ぐ

MyBatis の Mapper XML のように SQL を XML に書いていると、IntelliJ IDEA のコード整形が SQL の中の連続した空白を1つに詰めてしまい、意図しない差分がコミットに混ざる。チームで Eclipse と混在していると特に目立つ。

（2023-04 時点のメモ）

## 対処

設定 → エディター → コードスタイル → XML → 「その他」タブで、次の2つを設定する。

- 「属性の折り返し」を「折り返さない」にする
- 「空白を維持する」にチェックを入れる

![XML のコードスタイル設定](https://user-images.githubusercontent.com/74767283/229340292-20f3ce36-f4a3-44d3-b603-cdeef7514623.png)

## あわせて変えておいた設定

- 自動コンパイルは既定でオフ。設定 → ビルド、実行、デプロイ → コンパイラー の「自動的にプロジェクトをビルドする」を入れておかないと、保存しても変更が反映されず混乱する
- Eclipse から移ってきたメンバーには、キーマップを「Eclipse (macOS)」にしておくと移行が楽だった
